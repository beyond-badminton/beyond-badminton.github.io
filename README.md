# Beyond Badminton - Tournament Generator

## Overview
Tournament Generator is a client-side application designed to help organize tournaments efficiently. It allows users to manage players, courts, and schedules, generating randomized matches while adhering to specific rules for fairness and balance.

## Features
- **Player Management**: Maintain a master list of players and select active participants for each tournament.
- **Court Management**: Define court names and availability blocks for scheduling.
- **Schedule Generation**: Automatically generate a schedule for doubles matches (2 vs 2) based on player availability and court slots.
- **Customizable Options**: Adjust parameters like matches per hour, allow singles matches, and more.
- **Privacy-Focused**: All data is stored locally in the browser's `localStorage`. No external servers or cookies are used.
- **Import/Export**: Easily transfer data between devices or browsers using CSV files.

## How It Works
1. **Players Tab**: Add players to the master list and select active players for the current tournament.
2. **Courts Tab**: Define court names and set their availability for specific time blocks.
3. **Schedule Tab**: Generate a schedule based on the active players and court availability. Fine-tune the results with various options.

## Privacy & Data
- All data is stored locally in the browser.
- No data is uploaded to external servers.
- Data can be cleared at any time using the built-in cleanup buttons or browser settings.
